# Contributing

GAVFS 1.0 is an early draft. Open an issue to propose changes or submit a pull request with clear motivation and example payloads.

Please prioritize provider-neutral fields, simple consumer integrations, privacy, accessibility, and backward compatibility. Explain whether a change is REQUIRED, SHOULD or OPTIONAL and how consumers should behave when a field is missing.

Please avoid adding rider authentication, dispatch or payment requirements to core 1.0.
